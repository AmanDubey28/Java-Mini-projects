# Scientific Calculator 🧮

A powerful and user-friendly scientific calculator that runs in the console. This project was built with Java and demonstrates a strong understanding of core programming concepts, including user input, methods, control flow, and error handling.

## Description

This is a text-based, menu-driven calculator that goes beyond basic arithmetic. It includes a comprehensive set of scientific functions, unit conversions, and robust input validation to provide a smooth user experience. The program is designed to be a single, self-contained Java file, making it easy to compile and run on any system with a JDK.

---

## Features ✨

* **Basic Arithmetic**: Addition, subtraction, and multiplication for two or more numbers.
* **Advanced Math**: Functions for division, square ($x^2$), power ($x^y$), and the natural exponential ($e^x$).
* **Trigonometry**: Calculates sine, cosine, and tangent for angles given in degrees, as well as their inverse functions (arcsin, arccos, arctan).
* **Logarithms**: Computes logarithms for any valid number and custom base.
* **Number Systems**: Converts integers to their binary, octal, and hexadecimal (uppercase) equivalents.
* **Unit Conversions**: A dedicated sub-menu for converting between Celsius/Fahrenheit and Kilometers/Miles.
* **Scientific Constants**: A quick reference for key constants like Pi ($\pi$) and Euler's Number (*e*).
* **Robust Error Handling**: The application will not crash on invalid input (e.g., text instead of numbers). It provides helpful prompts and gracefully handles mathematical errors like division by zero.

## Getting Started

### Prerequisites

* Java Development Kit (JDK) version 11 or higher.

### How to Run

1.  **Clone the repository** (if you haven't already):
    ```bash
    git clone [https://github.com/aman7081/Java-Mini-projects.git](https://github.com/aman7081/Java-Mini-projects.git)
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd Java-Mini-projects/Calculator
    ```

3.  **Compile the Java code:**
    ```bash
    javac Calculator.java
    ```

4.  **Run the program:**
    ```bash
    java Calculator
    ```
    The calculator menu will appear, and you can start performing calculations.
